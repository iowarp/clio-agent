Web and command line

Use the interface that fits
where you work.

Desktop is the simplest start. For servers and development environments, install CLIO once and open the same workspace in your browser. The terminal UI remains available as an optional interface.

Browser workspace

Install CLIO, then launch the web app.

$ curl -fsSL https://raw.githubusercontent.com/iowarp/clio-agent/main/install/install.sh | bash
PS> irm https://raw.githubusercontent.com/iowarp/clio-agent/main/install/install.ps1 | iex
clio --webopens the workspace in your browser
Containers

Run the web stack with Docker.

$ docker run --rm -p 8080:80 ghcr.io/iowarp/clio-web:0.9.2

Open http://localhost:8080. Headless API and TUI images are also published with each release.
