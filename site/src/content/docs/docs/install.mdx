CLIO, ask for its connection address and the model you should use; you may only
need to connect to that existing service.

## Install the desktop app

<Steps>

1. Open the [CLIO releases](https://github.com/iowarp/clio-agent/releases) and
   choose a **published** release. A draft release is still being prepared.
   The published beta checked for this guide is
   [beta 5.2](https://github.com/iowarp/clio-agent/releases/tag/v0.9.5-beta.5.2).

2. Download the installer for your operating system. For an installation that
   includes the CLIO service, choose a filename containing **bundled**.

   | Your computer | Usual bundled installer |
   | --- | --- |
   | Windows x64 | `x64-setup-bundled.exe` or the bundled `.msi` |
   | macOS with Apple Silicon | `aarch64-bundled.dmg` |
   | Linux | The bundled `.deb` or `.rpm` matching your system and architecture |

3. Run the installer, then open **CLIO** from your applications menu.
   Allow the first startup to finish; preparation can take longer than later launches.

4. Choose the service where your work will run. For a bundled local installation,
   use the service for **This computer**. To use a lab service, connect to the
   address your administrator supplied.

</Steps>

An **attach-only** installer provides the interface and needs an existing CLIO
service. This is useful for a lab deployment; it is not a complete local install.
Some platforms, including Intel Macs, offer this option without a bundled installer.

<Aside type="note" title="macOS first launch">
The current app uses an ad-hoc signature. If macOS asks for approval after you
open the downloaded app, use **System Settings → Privacy & Security → Open Anyway**.
A failed checksum or an invalid signature is an installation problem; do not
bypass those failures.
</Aside>

## Choose the AI model

Installing CLIO does not install an AI model or supply a provider account.
[Choose a model](/docs/connect-a-model/) using the account, local model, or lab
endpoint you already have. Model calls use that provider's resources and limits.

Then follow [Your first analysis](/docs/examples/check-a-dataset/).

## Update an existing installation

<Aside type="caution" title="This release needs a full reinstall">
This release replaces agent blueprints with plugins and does not carry over data from earlier releases: saved sessions, blueprint agents, settings, and installed marketplaces. Before installing it, uninstall the earlier release with `clio uninstall --purge` and delete the folders listed under [What stays behind](/docs/uninstall/#what-stays-behind), including each workspace's `.clio` folder. Then install as on a new machine. Export any conversation you want to keep first; see [Exports](/docs/exports/).
</Aside>

Open **Settings → Desktop → App updates**. **Enable beta updates** allows
published beta releases for Desktop and the Agent. Changing the switch does not
itself install an update or downgrade the app. Older Desktop builds may need a
manual upgrade before this setting is available.

Some guides show controls implemented for the next release.
[Features and versions](/docs/versions/) identifies those differences.
