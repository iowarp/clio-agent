Bring evidence or an existing document into your workspace, describe the result you need, and review it before sharing. CLIO can create complete Word reports and PowerPoint presentations, revise Office files and work with PDFs and Excel workbooks. Office results keep their editable source alongside a saved PDF preview.

:::note[About the examples]
The recordings use fictional sensor observations and real document files. They
show the current interface, document revisions and visual review; the sample
readings are not evidence from a field trial.
:::

## Start with a file

Put the file inside your workspace folder. Type `@` in a message and choose its name from **Workspace files**. The reference tells CLIO which file you mean; add the change you want and anything it should preserve.

![Choosing a Word document from the workspace reference picker](/media/files-sensor-reference-picker.png)

To read a PDF yourself, open **Files** in the workspace canvas and select the
file. Expand the canvas for a larger view. Scroll through the pages continuously;
zoom controls sit in the upper toolbar and the page count appears at the bottom.

## Create a report or presentation

Start with the material you want CLIO to use and describe the audience and purpose.
You do not need to select a document library or write a layout script yourself:

> Create a Word report and a PowerPoint presentation from the analysis and figures in sources/ for a fifteen-minute team meeting. Explain the findings and uncertainties, include source captions and speaker notes, and save the editable files and PDF previews in outputs/. Keep the source files unchanged.

Include the intended length, a template or visual style, and any sections you
need. For a report, that might be an executive summary, findings, methods and
recommendations. For slides, describe the story you want to tell and how much
time you have to present it.

CLIO's document skills provide library references, design guidance and runnable
examples. The [report and presentation example](/docs/examples/reports-and-slides/)
includes editable files, reviewed previews and scripts you can use as references.

### Review the result

Open the resulting artifact beside the conversation. Read its saved PDF preview,
navigate the pages or slides, and zoom in on tables, figures and small labels.
Ask for corrections in the same conversation, then review the updated preview
before downloading or sharing the editable file.

## Close the visual review loop

Saving a document is the start of review. CLIO's document skills instruct the agent
to reopen the editable file, convert it to PDF and render page images. Each render
also provides labelled contact sheets containing up to six pages in a two-column,
three-row grid. These help reveal inconsistent layout, pagination and spacing.

The agent uses the overviews to decide which individual pages or slides need a
closer look. Small or unclear labels, suspected wrapping, table splits, glyphs or
cropping call for detail review; opening every page is not required. When the
source changes, CLIO should regenerate the preview and review the new overviews,
inspecting details as needed before publishing. If conversion or visual inspection is unavailable,
it should explain that limitation rather than claim the layout is verified.

You can review the published PDF beside the conversation, zoom for detail and
download the original editable file. Rendering with LibreOffice can differ from
Microsoft Office; open the source in your intended editor for final acceptance.

## Revise a Word document

Be explicit about both the edit and the parts that should survive:

> Make the recommended next steps explicitly request calibration records, matched source readings and a documented raw-data review. Keep the headings, editable tables, figure and theme. Save the revised Word file and a visually reviewed PDF in outputs/; preserve sources/.

CLIO reads the existing report, makes the change, renders the result and publishes
the revised document. Open the artifact to inspect its saved PDF preview. Check
that the revised recommendations fit the report and that its tables and figures survive.

## Update a presentation

Reference an existing deck and describe the change. Ask CLIO to preserve its
theme, charts, editable objects and notes. For example, revise the final
recommendations and speaker notes to distinguish the observed summaries from
conclusions that need calibration and matched raw readings.

For a workbook, specify the cells or calculation to change and which formulas
must survive. Review both the recalculated values and the printed sheet layout;
a PDF preview alone does not establish that formulas were preserved.

| File | Useful requests | What to review |
| --- | --- | --- |
| PDF | Read or extract content, inspect pages, create a report | Page layout, images and extracted text |
| Word (`.docx`) | Revise text, preserve a template, create a report | Headings, tables, images and pagination |
| PowerPoint (`.pptx`) | Update a deck or create slides | Slide overviews, with a closer look at text placement and images where needed |
| Excel (`.xlsx`) | Change cells, keep formulas, create a workbook | Recalculated values, formulas and printed sheet layout |

The model and the document's structure affect what can be preserved. Ask CLIO to inspect and explain any unsupported object or rendering failure before you treat the result as ready.

## Keep the editable result

The preview is for reading. The artifact retains the Word document, deck or
workbook that produced it. Use **Open in** to choose its PDF preview or download
the editable source. **Copy path** creates an editable working copy and copies
its path. Desktop also offers the default app and installed Word, PowerPoint or
Excel applications for the matching file type. Configured browser editors appear
when available; an unavailable editor cannot start a new editing session.

Make another request to produce a further revision, then review its new preview.

Each saved preview belongs to a particular source version. If conversion fails, the editable artifact remains available and CLIO reports the failure. A separate PDF export can also be useful for sharing, but it does not replace the editable file.

## Draft a message to accompany it

Ask for an email draft when you need to explain the changes to a colleague. The [Message draft widget](/docs/widgets/message-draft/) lets you compare alternatives and edit recipients, subject and body. Copy the draft or open it in your mail composer for review and sending. This is a handoff to your composer; CLIO's draft widget does not send the email.

See the [human-agent interaction gallery](/docs/widgets/interaction/) for other ways to review a choice, and [Memory and evidence](/docs/memory-and-evidence/) for how CLIO records the files and actions behind a result.
