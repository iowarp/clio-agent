Relay lets an agent work on computers other than the one it runs on: a cluster you
reach over SSH, a TACC system through Tapis, an ALCF system through Globus Compute,
cloud machines from SkyPilot, or the computer relay itself runs on.

Relay is a standard [MCP](https://modelcontextprotocol.io) server. CLIO uses it
through its relay plugin, which adds a **Compute** page to CLIO's left bar. Claude
Code, GitHub Copilot CLI, Codex or any other MCP client can run it with one line of
configuration, and gets the same five tools.

## Endpoints and sites

Each computer you add is an **endpoint**. Relay's own files and command line call
it a **site**; the two words mean the same thing. You keep your endpoints on the
[Compute page](/docs/compute/) or with `clio-relay site`. The agent uses the ones you
added. It never adds, changes or removes one itself.

Each endpoint has a **protocol**, the way relay reaches it, and a **security**
setting:

- **Secure** runs only packages someone has reviewed, and asks before it spends an
  allocation. In relay's files this is `guarded`, and it is the default.
- **Open** runs what the agent writes. In relay's files this is `open`.

See [Guardrails](/docs/relay/guardrails/) for what Secure checks.

## The five tools

| Tool | What it does |
| --- | --- |
| `describe` | With no arguments, lists your endpoints. With `site`, describes one endpoint: what it runs, its queues and what is needed to use it. With `job`, reports on one operation. |
| `run` | Submits a batch job, written as a [PSI/J](https://exaworks.org/psij) job spec, and follows it to the end. Also cancels and resumes a job. |
| `exec` | Runs one command on the login side, without a shell, and returns its output. |
| `files` | Lists, reads, writes, deletes and stages files. See [Files](/docs/relay/files/). |
| `serve` | Starts a long-running service, such as a Jupyter server, an MCP server or a web app, and forwards its ports to you. See [Serve a service](/docs/relay/serve/). |

`run` and `serve` can take a long time. A client that supports the MCP tasks
extension gets them as tasks: it sees progress, can leave and come back, and answers
questions, such as a one-time code or a spend approval, through the task. A client
without tasks gets an operation id instead and follows it with `describe(job=...)`.
CLIO supports tasks.

## Protocols

| Protocol | Reaches | Tools |
| --- | --- | --- |
| [SSH](/docs/relay/ssh/) | A login node, with your own `ssh` and keys | All five |
| [Worker](/docs/relay/worker/) | A login node, through a small relay worker that dials out | All five |
| [Tapis](/docs/relay/tapis/) | TACC systems, and your own host registered with Tapis | describe, run, files |
| [Globus](/docs/relay/globus/) | A Globus Compute endpoint, such as ALCF Polaris or NCSA DeltaAI | describe, run, files |
| [IRI](/docs/relay/iri/) | A facility's IRI API | describe, run, files |
| [SkyPilot](/docs/relay/skypilot/) | Cloud machines SkyPilot launches | describe, run |
| [Local](/docs/relay/local/) | The computer relay runs on | All five |

An endpoint can also list **alternatives**: other protocols that reach the same
machine. When the protocol in use does not take a tool, the first alternative that
does takes it. An alternative whose settings are incomplete is skipped, and the
answer says why. `describe(site=...)` and `clio-relay site show` list which protocol
takes each tool. A tool that no protocol on the endpoint takes answers with the
refusal `verb_not_implemented`.

## The catalog

Relay ships a catalog of endpoints it already knows. Adding one from the catalog
fills in its address, protocol and defaults, and links a skill that tells the agent
how that machine works.

| ID | Name | Protocol |
| --- | --- | --- |
| `ares` | Ares | SSH |
| `ares-tapis` | Ares (through Tapis) | Tapis |
| `aurora` | ALCF Aurora | Globus |
| `chameleon-tapis` | Chameleon node (through Tapis) | Tapis |
| `deltaai` | NCSA DeltaAI | Globus |
| `polaris` | ALCF Polaris | Globus |
| `stampede3` | TACC Stampede3 | Tapis |
| `vista` | TACC Vista | Tapis |

A machine that is not in the catalog can still be added on any protocol. See
[Bring your own machine](/docs/relay/bring-your-own-machine/).
