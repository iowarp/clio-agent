import { Steps } from '@astrojs/starlight/components';

<Steps>

1. Open **Settings → Marketplaces & blueprints**. Choose the workspace view you need.
2. On **Marketplaces**, browse an existing collection or choose **Add marketplace**. Follow the [illustrated add and reload guide](/docs/marketplaces/manage/) to select its location and workspace access.
3. On **Installed**, search for the blueprint and choose **Details**. Read its overview, instructions, and connected services.
4. Create a new session and select the blueprint in **Agent blueprint**. Choose a configured model before sending a request.
5. Return to the marketplace when you want to reload or remove an installed copy. Compare available and installed versions before assuming an update is active.

</Steps>

The [marketplace walkthrough](/docs/marketplaces/) shows the real interface. The [blueprint authoring reference](/docs/blueprints/) explains how to create your own collection.
