# App view

An MCP App view opened by a tool call, with its state linked to the surface's data model.

Component `clio.mcp-app.v1`. Place a connector's interactive view in a dashboard and link its time step, selection or parameters to the charts, tables and maps beside it.

The site shows a live example, its fields and the agent's skill for it.
