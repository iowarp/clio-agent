# Raster viewport

An interactive viewport for a registered grid (one 2-D field, or one frame of a time series), with sampled values, colour scale, and region reference.

Component `clio.raster-viewport.v1`. Inspect a spatial field or image, including regions that can be captured for a follow-up question.

The site shows a live example, its fields and the agent's skill for it.
