# 3D viewport

An orbitable 3D view of a registered standard mesh or a CLIO FEA mesh with optional result fields.

Component `clio.mesh-viewport.v1`. Orbit a scientific 3D mesh and compare geometry or field results from different design states.

The site shows a live example, its fields and the agent's skill for it.
