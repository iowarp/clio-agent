# Bring your data into CLIO

Choose how to attach files, refer to existing work or connect a source.

Give CLIO the material you want it to work with, then say what you want done. **Attach** brings in files, folders, or connected data. **Reference** points to material already in the workspace.

![The composer plus menu offers Attach and Reference](plugin-asset://guide/captures/guide-context-menu.webp)
*Start with the plus button beside your message. You can also type @ to find existing material.*

## Choose your next step

| I want to… | Use | What changes |
|---|---|---|
| Add a file or folder from my computer | [Attach](docs/files/attach.md) | CLIO prepares it in the workspace and adds it to your draft. |
| Ask about a file, result, or earlier conversation | [@ references](docs/files/references.md) | A reference is added to the message; no second upload is needed. |
| Use Drive, GitHub, Globus, or an SSH folder | [Connect a source](docs/files/connect.md) | CLIO saves a source for this workspace. You then choose how to use its files. |
| Find NDP datasets or query an existing Endpoint | [National Data Platform](docs/files/ndp.md) | Select resources to link or download, or retain API and stream responses. Requires CLIO v0.9.5-beta.8 or later. |
| Explore an Obsidian vault or a folder within it | [Research notes](docs/files/knowledge.md) | CLIO opens a graph, file list, and reader, and enables knowledge tools for the agent. |
| Decide whether edits affect the originals | [Download or link](docs/files/download-or-link.md) | Your choice sets where the files live and where changes can go. |
| Reuse, unlink, or remove a source | [Manage sources](docs/files/manage.md) | You control the connection separately from individual messages. |

## A source is not a message

Saving a source makes it available in this workspace. Adding a file or folder to the composer selects it for your next request. **Send** delivers the message and its attached context to the agent.

You can inspect or remove an item before sending. Removing a draft reference is different from deleting a file or removing a saved source; the [management guide](docs/files/manage.md) explains each action.

The walkthroughs use a small example folder called **Project notes**. They show real interface states, presented as captioned screenshot walkthroughs.
