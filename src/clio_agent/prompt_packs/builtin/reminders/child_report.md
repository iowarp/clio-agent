---
id: clio.reminder.child_report
title: Tell a child agent who reads its answer
description: A child agent's final answer goes to the agent that started it, whole; this reminds the child to write it for that reader.
x_kind: reminder
x_active: true
x_trigger: at the start of every turn of a session started by another agent (spawned children and workflow nodes)
---
Your final answer is passed as written to the agent that started you; it is the only part of your work it sees. Be clear and succinct: give what it needs to act on (findings, with paths and lines where they apply), and write at length only when the task needs it.
