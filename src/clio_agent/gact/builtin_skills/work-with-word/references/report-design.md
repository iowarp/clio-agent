# Report design

## Establish the report before formatting

Read the supplied material and identify who will use the report, what question it
answers and which claims the sources support. Use a concise opening summary with
the principal finding, its confidence and the next decision. Follow with enough
context and method to understand the evidence, findings in a useful order,
limitations and next steps. Adapt this structure: an operational report and a
scientific report do not need identical sections.

A report should explain relationships and implications in connected paragraphs.
Use bullets for genuinely parallel findings or actions. A heading followed only
by one bullet is often an outline rather than developed content. Choose length
from the evidence and intended use; do not pad with generic prose or collapse a
substantial analysis into a one-page fixture.

Keep reported facts, interpretation and proposed work distinguishable. Record
where figures and numbers came from, their units, exclusions and uncertainty.
Do not strengthen an exploratory association into a causal conclusion.

## Use document structure to carry the design

Set page size and margins explicitly. Start with 11–12 pt body text, a readable
font available on the execution host, and consistent paragraph spacing. Use
native Title, Heading 1 and Heading 2 styles; avoid manually enlarged paragraphs
that only look like headings. Maintain a small type hierarchy, one restrained
accent colour and aligned left edges. An internal report usually does not need
a mostly empty cover page.

Use section breaks when orientation or headers change. Add page numbers to a
multi-page document. Keep headings with the following paragraph, enable widow
control and keep captions beside their figures. Use deliberate page breaks only
when they improve a specific page; blank paragraphs are not a spacing system.

## Treat tables and figures as evidence

Make tables native and editable. Use meaningful column headings, units and
explicit widths that fit the page. Repeat the header row when a table continues.
Split a very wide or long table, use a landscape section or move full detail to
an appendix instead of shrinking everything to unreadable text.

Keep image proportions. Prefer the highest useful source resolution; do not
stretch a thumbnail into a page-wide figure. Check labels at the size the reader
will actually see. Crop or present separate panels only when this preserves the
evidence and makes it easier to read. Captions should state what the figure shows
and any material caveat, with a source reference. Do not replace charts with
decorative illustrations or flatten body text into an image.

## Finish with a page review

Reopen the DOCX to check structure and retained objects. Render it and inspect
the page overviews, including the last page's flow. Look for heading orphans,
unexpected blank pages, table splits, clipped text and misplaced images. Use what
the overview shows to choose individual pages for detail review; check small labels
or headers/footers when they are unclear at overview scale. There is no requirement
to open every page individually. Review paragraph quality as well as overflow.
Revise the native source and regenerate its preview; an old PDF cannot verify a new DOCX.

Publish the editable source with its version-bound preview. A PDF is useful for
reading, but does not replace the requested Word document.
