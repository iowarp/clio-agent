the hard way, which you should adopt: after launching, watch the SUBMISSION
handle itself — the wait/observe follow-up on the job id the launch returned.

directory you were querying only ever materializes when startup succeeds, so
its absence just means the run failed early. Also from the previous shift:
the launch's own record and its listed artifacts (the run job's stdout and
stderr) carry the render stage's actual crash output. Read the record of the
