# Session export contract

The sidebar export menu delivers **one self-contained HTML file** by default (Transcript). CSS, JavaScript, visual dependencies, complete raw transcript/semantic events, saved tool outputs and loaded skill text are embedded. No companion files are required. Effects delivers a ZIP containing that visual review plus recorded skill files, raw JSON/traces, session/descendant artifact versions, producing input closure, and explicitly recorded context/transform input paths. Full adds registered workspace roots at export time, excluding `.git`, `.venv`, `node_modules`, `__pycache__` and `.clio`. Workspace `.tmp` content remains eligible. Symlinks and Windows reparse points are never followed.

Effects and Full contain `index.html`, `transcript.json`, full per-session semantic JSONL in `traces/`, recorded loaded skill bodies in `skills/`, and `manifest.json` with SHA-256, byte counts, archive paths, artifact identities, omissions and workspace snapshot timing. Loaded instructions expand with the native Show more control at their own tool call; Evidence and skills supplies an additional index inside the HTML. Child sessions retain their relationship records. Source/editable artifact bytes and generated previews keep separate artifact identities and files.

All modes include complete saved outputs from the selected sessions' canonical `tool-output` stores. The server enumerates those owning directories; paths supplied in recorded results never authorize arbitrary reads. Other sessions, links and nonregular files are excluded. Transcript embeds complete readable output text and original bytes. Effects and Full also provide the files separately, with portable links, hashes and export-time identity. Missing stores or streams remain explicit gaps.

Raw transcript construction flushes the durable semantic trace and reads full events rather than the bounded UI/SSE projection. Semantic tool events are joined by call ID; missing legacy fields are preserved from message records and labelled. Exact skill content is now recorded durably at load time, with a small hash/metadata-only live activity projection. Older skill events can use their original recorded `load_skill` response, never the currently installed package. Parallel legacy loads are matched by skill and requested file identity; ambiguous matches remain explicit gaps. A legacy body marked `complete_tool_response` retains the entire original response, including any batched references. If a cold ARC projection fails and the configured durable message copy exists, export uses that copy and reports the projection failure. With that copy disabled or unavailable, export fails explicitly.

The UI captures the existing session catalog, validated A2UI surfaces, reference resolutions, owned media bytes and all source table pages. A production-validator projection of recorded parts is available when the live ARC projection is degraded. The offline page uses the same component renderer and a local transport. It supports client interactions and local filter/aggregate/sort/page/stride/LTTB table queries, preserves row keys, and rejects agent mutations. Remote media, map tiles and uncaptured dependencies are unavailable offline and appear in coverage. The HTML embeds classic JS/CSS, gzip/base64 visual data and the official map worker, with CSP hashes for the shipped scripts and no live connections. No bearer credential enters the archive. Modern browsers decode the data locally with DecompressionStream. A complete script-free Markdown document remains visible until enhancement succeeds; decode or renderer failures retain it. Recorded text is escaped, and raw HTML/active links are rejected. Complete raw records, including semantic events, remain embedded; exact JSON is formatted only when expanded.

The enhanced conversation uses the production `transcript_entities` projection and the same `ConversationMessageRow`, Activity, tool, reasoning and presentation components as the live UI. Recorded invocation identities join commands and results in their original iteration, and full durable presentation bodies replace the live projection's bounded previews. The raw ledger remains unchanged. Answered questions retain their invocation relationship and fold into that tool's Activity; archive construction includes every retained question without the live attention tray's result cap. Native Chain and Full activity views, Show more, tool information and full-result controls work locally.

Historical errors remain visible even when output is empty. Exact envelopes are supplementary Evidence, rather than a JSON disclosure on every message. Included source links resolve only through recorded artifact/input identities or the exact Full workspace inventory; arbitrary original-host paths are never opened. Ambiguous or unavailable sources remain explicit. Captured raster previews remain readable without JavaScript, including recorded workspace-media redirects. Both the viewer JavaScript and export data are compressed inside the HTML; hashed inline loaders decode them without companion requests.

API:

- `GET /v1/sessions/{sid}/export`: full raw JSON, retaining the legacy version-1 message import shape plus `clio.session-export.v2` extensions.
- `GET .../export-review`: small validated visual-capture input, avoiding large raw trace responses through the Desktop bridge.
- `POST .../export-download`: `{mode, visual_review: {javascript, stylesheet, snapshot}}` prepares Transcript HTML or an Effects/Full ZIP and returns `{download_path, filename}`. The renderer is shipped with this UI build. The server controls transcript and file selection; snapshot fields are never treated as filesystem paths.
- `GET /v1/session-export-downloads/{ticket}`: one-use, archive-only capability prepared under bearer authentication; expires after 20 minutes, pending pool limited to eight. Streams from a temporary file to the browser download manager, avoiding ZIP-sized UI/bridge buffers. Successful consumption or expiry removes the file.
- `POST .../export`: direct authenticated visual HTML/ZIP download for API clients, following the selected scope.
- `GET .../export?mode=transcript|effects|full`: headless HTML for Transcript, ZIP for Effects/Full, with a script-free readable review; interactive A2UI review requires the UI's captured renderer and dependencies.

Files are copied in 1 MiB chunks with Zip64 and checked for changes. Recorded hashes must match. Changed bytes or read failures fail the archive and remove its temporary file; unavailable recorded versions and excluded paths appear in the manifest. Export is an evidence review/snapshot, not an executable replay or automatic full-workspace import. Active sessions are captured through export time and can continue afterward.

Qualification includes lossless large tool/skill content, child sessions, historical gaps, cold projection recovery, scoped effects, full workspace exclusions, overwritten-byte failures, temporary cleanup, real Windows junction confinement, capability authentication/expiry/single-use, UI scope toggles, searchable large choice groups, image enlargement, question folding, table pagination/sampling/row identity, production builds, and real OPAL archive review. Live evidence and remaining platform qualification are recorded in the PR.
