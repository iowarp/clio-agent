# Acceptance ledger: plugins, Agent SDK and flows

Rows follow [megachange-plan.md](megachange-plan.md). A row passes only with recorded evidence: test names and results, commands, task handles, and for UI work the screenshots that were read. Status says what kind of evidence it is:

- `passed (live)`: exercised against a running CLIO (sessions, task handles, CLI output or screenshots that were read).
- `tests only`: covered by the named tests; not exercised live. Not counted as a live pass.
- `static`: checked by reading the tree (grep, diff, a file on disk); nothing to run.
- `done`: a recorded decision with no behaviour of its own.
- `open`, with the issue that tracks it, or `blocked`, with the reason it cannot run in a cloud session. Only the platform rows the plan names (Tauri desktop, Windows-only paths, SSH to HPC systems) and accounts or devices the cloud session lacks may be `blocked`.
