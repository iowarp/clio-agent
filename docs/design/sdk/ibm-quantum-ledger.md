# IBM Quantum in CLIO: ledger

This ledger holds the decisions and acceptance evidence for [the IBM Quantum plan](ibm-quantum-plan.md).
Decisions follow the plan's prefixes: `QC` connector, `QS` server and simulation, `QV` views,
`QF` feedback, `QP` plugin, `QQ` qualification scenarios. A decision made while building is
suffixed `-D` (for example `QC-D1`).

Status vocabulary (as in the [apps ledger](mcp-apps-ledger.md)): `passed (live)`, `tests only`,
`static`, `done`, `superseded`, `open`, `blocked` with the reason.

| Model and backend | Job | Test accuracy |
| --- | --- | --- |
| Hybrid, `local_exact` | `local-ddb3c95462b34638` | 0.73 |
| Hybrid, `fake_fez` (seed 11) | `local-a49bbe1d685d4e53` | 0.73 |
| Classical baseline | (PyTorch, no backend) | 1.00 |

Noise contracted the values toward 0 (fitted slope 0.88, mean absolute shift 0.052); no image changed class; images 6, 56, 50, 44 and 84 sit within 0.05 of the threshold.
