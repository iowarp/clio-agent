## Contract differences found while reconciling with `conn-be`

| ID | Difference | Handled |
| --- | --- | --- |
| CD1 | Need rows also carry `options: [str]` (a value from a list) | Read; the card shows a picker |
| CD2 | `scope.agents` holds agent **refs**, and must be non-empty | The UI sends refs; Enable is disabled with no agent chosen |
| CD3 | A custom connector is removed with `DELETE /v1/connectors/{id}`, and only a custom one can be | `removeConnector`; Remove (with an inline confirm) appears only on a custom connector's card |
| CD4 | `GET /v1/connectors` also returns `diagnostics` for entries that did not load, and `?refresh=true`; `GET /v1/connectors/{id}` exists | Not used by the UI yet |
| CD5 | The `connector_setup` payload also carries `interaction_id`, `connector_name` and `logo_url`; its id is `connector:<hex>`; a declined card's status is `denied` | `connector_name` is the card's fallback name; `denied` reads "declined" |

| CD7 | A saved MCP connection is not a connector. "Add by URL or command" therefore creates through `POST /v1/connectors` (CN12 row) | — |
