# Ledger fragment: `pv-ui` (ParaView controls in the view)

The person, looking at the ParaView view in a full-width tab, asked for "more of the ParaView control available, like a toolbar on the left", with compact icons and short tooltips rather than prose, and later for the view to take CLIO's tone (light and dark) instead of pure white. This stream builds that working surface in the view (`ui://paraview/view` and the trame app in the node half, `paraview_mcp/node/`). All of it lives in clio-kit; clio-agent gets only the harness and this fragment.

Branches `ws/pv-ui`: clio-kit (the server, 3.0.0 to 3.1.0), clio-agent (harness, ledger; merged `claude/parallel-agents-plan-uzpzm0` for the host's theme variables), gact-tui (a merge of the integration branch only). Stack N=18: agent 8818, UI 5218, `CLIO_CLOUD_ISOLATE=1`, `CLIO_ARC_CTE_FILE_CAPACITY=128MB`; ParaView 6.2.1 on this machine through the `paraview` connector with "Command to run first" set to put `/opt/pv6/bin` on the path.
