CLIO 0.9.7 gives the agent built-in web and scholarly search, lets it see the images a script opens, and removes the hard time limits on its work. The interface is finished to its design and now speaks Spanish, Japanese and Greek as well as English. Desktops on 0.9.6.x and 0.9.5.1 offer the update.

## What the agent can do

### Web and literature search, built in

Web search no longer needs a search server on your computer. `web_search` and `web_fetch` are now part of CLIO and ask hosted sources (Keenable, Exa, Firecrawl, You.com and Parallel) in the order you set. New `literature_search` and `literature_lookup` tools search OpenAlex, Crossref, arXiv, Europe PMC, OSTI.gov, DataCite and OpenCitations, and Semantic Scholar when you add its key. No key is needed: CLIO asks you before the first query to each source, and again when a source's free allowance runs out, and a failed search says why. Settings > Web search orders the sources and holds their keys. (#2283, iowarp/gact-tui#1234, iowarp/clio-agent-marketplace#133)

### Deep research that delivers its report

Deep research now finishes. Its researcher and critic search the scholarly sources too, the report carries full references for the papers it cites, and a claim the critic can't support is dropped with a note instead of stopping the run. In our checks it delivered a report with 81 citations and the reviewer's open questions. (#2283, iowarp/clio-agent-marketplace#133)

### The agent sees what its scripts look at

When the agent opens an image from inside a script (a plot, a page render, a figure), the image now reaches the model. If a view could not be shown, the agent is told, and the PDF skill names the pages it could not check instead of saying it verified them. (#2272, iowarp/clio-agent-marketplace#132)

### PDFs go where you asked

"Turn notes.md into a PDF called notes.pdf" now writes `notes.pdf` where you asked, under the name you gave. It used to put most PDFs under `output/pdf/` and leave a `tmp/` folder in your project. Folders CLIO uses for document work also get a `.gitignore`, so `git add -A` no longer picks up its files. (iowarp/clio-agent-marketplace#131, #2259)

### No time limits on long work

A document conversion, LaTeX build, file search or browser action runs until it finishes or you stop it; conversions used to be stopped after 60 to 120 s. A step that stops making progress shows as stalled on its row, and Stop ends it with all its processes. When a Claude Code reply goes quiet, CLIO waits and retries at growing intervals and shows each wait in the conversation, instead of failing the turn after 2 minutes. (#2262)

### A fast model for helper work

You can choose a fast model in Settings > Models. Helper work you haven't given its own model (goal and permission checks, the explore subagent, CLIO Search and the memory pass) runs on it instead of on the conversation's model. The same page sets which accounts may run delegated work. (#2266, iowarp/gact-tui#1226)

### Marketplaces you remove can come back

Removing a marketplace and adding it again works. On Windows the second add used to fail with "Cannot create a file when that file already exists". (#2271)

### Steadier conversations

- A turn whose error led back to an earlier error now ends; one such turn stayed "running" for 55 minutes. (#2240)
- A Claude Code reply that kept inventing tool results (one ran for 6 minutes and 128,000 tokens) now stops after its first call, and the call runs as usual. (#2259)
- An answer the model service replaced with an empty placeholder is sent again instead of being shown as the answer. (#2259)
- A reply that fails after partial output offers Retry. (iowarp/gact-tui#1180)
- "This folder" in a new conversation means its workspace. (#2259)

### Deleting conversations and workspaces

A conversation you stopped can be deleted; before, the delete failed with "409 Conflict". Removing a workspace deletes its conversations, as the dialog says, and when work is still running the app says why it can't delete yet. (#2250, #2259, iowarp/gact-tui#1216)

## The interface

CLIO 0.9.7 ships gact-tui 0.13.0, which finishes the interface introduced in 0.9.6.

### In your language

The whole interface, the Desktop menus, Desktop errors, the update reason and the landing page are available in English, Spanish, Japanese and Greek. Choose the language in Settings > Appearance > Language, or let CLIO follow your system. The three translations are machine-made and marked as such until a native speaker reviews them. (iowarp/gact-tui#1232, iowarp/gact-tui#1237, iowarp/gact-tui#1241, iowarp/gact-tui#1242, iowarp/gact-tui#1243, iowarp/gact-tui#1244, #2279)

### A tour for new users

A first launch starts a short guided tour of the interface. You can replay it from Settings > General. (iowarp/gact-tui#1155, iowarp/gact-tui#1162, iowarp/gact-tui#1168, iowarp/gact-tui#1214)

### See what tools and agents carry

Settings shows each MCP server's tools in the same rows as built-in tools, with their permissions, and every tool opens its details. The agent view shows the agent's packages and its full prompt, and its subagents and skills open on their own pages. (#2267, iowarp/gact-tui#1227, iowarp/gact-tui#1228)

### Transcript and workbench

- A script's tool row shows what the script ran, the images it viewed and whether the model saw them. Show the task in Work opens the run, and Open in tab shows its printed output. (iowarp/gact-tui#1229)
- The conversation rail docks beside the transcript while the side pocket is closed, and rows show "New activity" for conversations you don't have open. (iowarp/gact-tui#1203, iowarp/gact-tui#1209)
- Switching conversations no longer redraws the whole window. (iowarp/gact-tui#1190, iowarp/gact-tui#1199)
- Workspace rows open their menu on right-click, and workspace settings live in Settings > Folders. (iowarp/gact-tui#1205)
- The lineage graph lays out with fewer crossing lines and supports zoom, pan and drag; code is coloured and wraps by default. (iowarp/gact-tui#1207, iowarp/gact-tui#1220)
- A PDF cited by the agent opens on the cited page, and paging and zoom keep your place. (iowarp/gact-tui#1179, iowarp/gact-tui#1201)
- A comment marked on an older version of a file says so and offers to mark it again on the current one. (iowarp/gact-tui#1212, iowarp/gact-tui#1224, #2246, #2258)
- Interface size now scales every piece of text. (iowarp/gact-tui#1211, iowarp/gact-tui#1217)
- A draft moved to another workspace keeps its model, agent and text. (iowarp/gact-tui#1223)

The [gact-tui 0.13.0 notes](https://github.com/iowarp/gact-tui/releases/tag/v0.13.0) list every change.

## Installs, uninstall and the website

- Windows installs unpack the source dependencies, LibreOffice, Node.js and npm from prepared archives, leave out Office parts CLIO never uses, and grant the sandbox access once. (#2228, #2241, #2253, #2254, #2257, #2275, #2276, #2277, #2244)
- The installer sets up Claude Code support during the install, and starts the LibreOffice download first. (#2242, #2248, #2251)
- On Windows, the installer offers to turn on long path support before it starts. (#2255)
- `install.ps1 --source --ref <tag>` works on Windows PowerShell 5.1. (#2237)
- On macOS and Linux, an install with its own CLIO home keeps its clio-kit inside that home. (#2230)
- A script-installed server starts in your workspace folder. (#2235)
- Uninstalling the Desktop leaves no CLIO cache in `~/.cache/uv` or `~/.npm`, and names a `clio.yaml` it keeps and how to remove it. (#2261, #2259)

## Changed

- CLIO no longer installs or runs SearXNG, and the Desktop no longer installs clio-kit's web search server. Search uses the hosted sources above.

## Fixed

- Connecting a model right after CLIO starts waits for it to be ready instead of failing with 503. (#2234)
- The "Protected execution needs attention" notice says what failed in a sentence instead of showing raw records. (#2234)
- Cancelling a model download on Windows stops it. (#2234)
- Two component checks at once no longer fail with a server error. (#2247)
- Codex finds CLIO's sandbox settings when your Windows profile is redirected, so protected execution passes its check. (#2236)
- After several Claude Code conversations at once, CLIO can reach the model again; one turn had waited 14 minutes for a connection. (#2259)

## Before you upgrade

- If your `config.yaml` or environment still sets a SearXNG key (`search.backend`, `search.clio_web_search.url`, `search.local_searxng.*` or `search.searxng.*`), CLIO stops with an error that names the key and where it is set. Delete those lines and start CLIO again.
- If you are coming from 0.9.5.1 or older, the notes for 0.9.6 apply: the installer offers to move old data aside, the default port is 17800, and CLIO Desktop for macOS needs macOS 15 or newer.

## Known issues

- The translations are machine-made and have not yet been reviewed by native speakers.
- In Greek and Japanese, some labels are cut off at desktop width: the CLIO menu, Infrastructure map nodes, some Settings rows and the shortcut sheet. Settings > Runtime and history is still in English in those languages. A patch release will fix both.
- Bell request rows can show a raw "destructive tool call:" title.
- Installs are faster but do not yet meet our one-minute goal on every system.
- On a fresh install with no conversations yet, attaching a newly connected Drive folder stops at "Choose a conversation to track this work". Start a conversation first. ([iowarp/gact-tui#873](https://github.com/iowarp/gact-tui/issues/873))
- On Windows without long path support, a CLIO home longer than 56 characters is refused by `install.ps1`. Keep the default home, use a short path, or enable long paths in Windows.
- A conversation can occasionally stop responding after a tool step. Cancel it and send the message again.
- Right after a release, the one-line install can report "no version of clio-agent" for up to 10 minutes while PyPI's index refreshes. Try again a few minutes later.

## Install

Desktop (the app plus its own agent):

- macOS 15 or newer (Apple silicon) and Linux: `curl -fsSL https://clio.iowarp.ai/desktop.sh | bash`
- Windows: `irm https://clio.iowarp.ai/desktop.ps1 | iex`

Agent and Web only (open it with `clio web`, or run it headless with `clio start`):

- macOS and Linux: `curl -fsSL https://clio.iowarp.ai/install.sh | bash`
- Windows (PowerShell): `irm https://clio.iowarp.ai/install.ps1 | iex`

You can also download an installer from the assets below. The `-bundled` files carry the agent with the app; on Windows the bundled installer fetches it once (about 630 MB) and works offline after that. The others download the agent on first launch.

- Windows: `CLIO.Desktop_0.9.7_x64_en-US-bundled.msi` or `CLIO.Desktop_0.9.7_x64-setup-bundled.exe`
- macOS: `CLIO.Desktop_0.9.7_aarch64-bundled.dmg`
- Linux: `CLIO.Desktop_0.9.7_amd64-bundled.deb`, `CLIO.Desktop-0.9.7-1.x86_64-bundled.rpm`, `CLIO.Desktop-0.9.7-1-x86_64-bundled.pkg.tar.zst` (Arch) or the `.AppImage` (arm64 builds are listed too)

The [installation guide](https://github.com/iowarp/clio-agent/blob/v0.9.7/docs/INSTALL.md) covers containers, source installs and uninstalling.

See the [CHANGELOG](https://github.com/iowarp/clio-agent/blob/v0.9.7/CHANGELOG.md). For a backend-only install: `uv tool install --python 3.14 --with dspy==3.4.0 --with fastmcp==4.1.2 --with fastmcp-tasks==4.1.2 --with mcp==2.2.0 clio-agent==0.9.7`
