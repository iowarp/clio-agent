CLIO 0.9.5.1 brings plugins, programmable agents and flows, studies with linked evidence, and a simpler installation and startup path.

### Install and open a workspace

One installer per operating system handles the agent or bundled desktop, with verified downloads and CLIO-owned Python and uv runtimes. Startup reads bounded history pages, and the documented Linux and Windows acceptance matrices cover cold and repeat installation, agent readiness and usable desktop workspaces. (#1875, #1889)

### Build agents from plugins and flows

Plugins assemble tools, skills, agents and hooks into reusable workflows. The Agent SDK and flows use the shared task layer, with retained results and explicit approval records for workflow steps. (#1825)

### Delegate work and fork an investigation

Delegation can copy the caller's tools, plugins and model, or use its read-only explore, planner and review roles. Agents can fork a conversation or workflow step with a note, within the configured approval and growth limits. (#1869)

### Keep studies connected to their evidence

The Science log links questions, hypotheses, experiments, observations and conclusions to recorded calls. Agent-built study views read live measurements and selected records, with linked viewers and CSV or Parquet exports. (#1869)

## Breaking

The legacy terminal UI (TUI) is frozen and unsupported. This release does not
publish TUI binaries or a TUI Docker image, and installers no longer build or
download it. Bare `clio` opens Web; `clio attach` reports the frozen status and
exits. Use [Desktop or Web](https://clio.iowarp.ai/docs/install/), including when
installing from Claude Code or another assistant. TUI source and integration
notes remain available for a future upgrade.

The plugin and agent-class model replaces the earlier blueprint system. Frontend session readers use bounded pages rather than the removed unbounded session-list APIs. (#1825, #1875)

## Known issues

- On Windows, the optional ADIOS MCP server fails to build its ADIOS2 native dependency in protected temporary storage. A first-start WebMCP identity race is also recorded. These optional-tool findings are tracked in [#1887](https://github.com/iowarp/clio-agent/issues/1887).
- The dependency audit still reports CVE-2025-69872 in transitive DiskCache 5.6.3. CLIO's serving path disables LM disk caching; the dependency finding remains open in [#1887](https://github.com/iowarp/clio-agent/issues/1887).
