This beta combines the workspace, model, native-service and connected-data changes
with interactive scientific artifacts and clearer progress during long work.

### Background work and session coordination
Inspect background commands, downloads and delegated work while continuing the
conversation. Shared task controls retain progress, results and recoverable
assignments; authorized sessions can exchange messages and query them by time.
(#1798, #1824)

### Session and Work
Keep context, sources and files in Session, with goals, questions and background
work in Work. Reorder or hide sections in Customize while expanded content stays
open. File views use one filename header with version and lineage controls, and
hover navigation stays temporary until pinned.
([UI #670](https://github.com/iowarp/gact-tui/pull/670),
[UI #671](https://github.com/iowarp/gact-tui/pull/671))

### Context and questions
Inspect how tools, skills, sources and messages contribute to the context. Add
details beside question choices and keep answer drafts when changing views.
(#1827, #1828)

### National Data Platform
Find datasets, filter publishers and select the resources to link or download.
Sign in through NDP's browser device flow, or connect an existing Endpoint by URL
or SSH. Authorized Endpoint operations include creating organizations and datasets,
uploading files and updating metadata. Bounded stream reads save their data and
checkpoint so the agent can analyze a capture and continue from that position.
The installed streaming_v2 runtime also supports authorized Kafka captures and
continuation without custom Endpoint stream routes. The default uses NDP's test
identity service; available operations depend on the Endpoint and account
permissions. (#1793, #1801, #1818, #1826)

### Scientific analysis and shareable conversations
Analyze linked read-only data with shell tools while the OS protects the originals.
Charts resize with their view and retain native selection controls. Portable HTML
conversations include their saved map geometry, and four multi-question NDP examples
show the source data, analysis and recorded tool activity.
([Examples](https://clio.iowarp.ai/docs/examples/ndp-science/), #1801, #1819)

### Readable tool activity
Inspect a tool's purpose, requested files and returned content before opening its
technical record. Skill loads show their description and distinguish instructions
from supporting reference files. Failed selections and retries retain their actual
cause and invocation history. (#1818)

### Interactive HTML and diagrams
Generated HTML can use WebGL and offline libraries, and HTML/SVG previews adapt
to their content and theme. Pele adds diagram options alongside the existing
visual tools, with explicit folder links and a capture-and-review workflow.
Dashboard layouts follow the content rather than a fixed column rule. (#1786, #1791)

### Workspace access
Edit primary and additional folder paths directly while preserving conversations.
When work needs an external folder, review the action, path and access duration,
then approve access and continue. Additional folders appear in Files, and files
actually used or written receive hashes and version records. (#1766, #1773, #1779)

### Models and long-running work
Filter models by context size, see provider and model names together, and open
large model catalogs progressively. Progress distinguishes waiting, reasoning,
tools and goal judging. Goal work reuses its model client across iterations;
ephemeral checkers close their owned clients after each check. (#1775, #1776, #1781, #1784)

### Questions and permissions
Navigate pending questions and permissions in one attention tray while retaining
draft answers. Required question bundles submit together. A decision inside a
generated interface links to the relevant tab without moving the entire interface
into the question area. (#1778, #1779,
[UI #648](https://github.com/iowarp/gact-tui/pull/648))

### Native services and updates
Choose native or container installation according to the connected computer.
Install llama.cpp before choosing a model and use its supported AMD options.
One product update coordinates Desktop with its managed Agent runtime. (#1785, #1787, #1794)

## Fixed

- Statistical distribution results through the updated scientific tool runtime.
- NDP catalog browsing without installing or importing a separate MCP server.
- Windows SearXNG archive extraction and bundled Python launch paths.
- Native MCP startup through the Windows fence, including private temp profiles,
  short runtime cache paths and the actual workspace directory.
- Release idle MCP processes after their work finishes.
- Inline math in conversations and Markdown documents.
- Rapid question-gallery switching that could expose two panels.

## Changed

- Configurable large pastes can become attached Sources with a clickable preview.
- Concurrent subagents, per-agent workers and nesting depth support Unlimited.
- Hide SSH hosts from pickers, or remove their saved CLIO entry after confirmation. (#1780)

See the [changelog](https://github.com/iowarp/clio-agent/blob/v0.9.5-beta.8/CHANGELOG.md)
for the complete changes.
