This is the second hotfix for the v0.9.6-beta.1 beta. It restores the Linux bundled desktop packages and includes everything in [v0.9.6-beta.1.1](https://github.com/iowarp/clio-agent/releases/tag/v0.9.6-beta.1.1): reliable LibreOffice downloads, a faster Linux one-line install and the fixes found in the first hours of the beta.

### Linux bundled desktop packages are back

The Linux bundled deb and rpm carry the CLIO runtime as one compressed archive. The packaging library compressed that archive a second time while building the rpm, and that second pass took hours, so v0.9.6-beta.1 and v0.9.6-beta.1.1 finished without Linux bundled packages. The rpm now stores the archive as it is, which builds in seconds and makes almost no difference to its size (#2090).

### Office files open straight into their preview

Opening a Word, Excel or PowerPoint file now shows its rendered preview right away instead of a "No viewer" page, and Export to PDF sits beside Download. The toolbar keeps one layout while the document converts (iowarp/gact-tui#1122, iowarp/gact-tui#1124).

### Installs no longer stall on a slow LibreOffice mirror

The document tools need LibreOffice, which CLIO downloads during install. About one download in ten went to a mirror slow enough to push the install past its time limit. CLIO now tries several mirrors at once, keeps the fastest, and switches to another mirror if the transfer slows down, resuming where it stopped. Every file is still checked against its pinned checksum (#2077).

### Faster Linux one-line install

On Linux, the one-line and `--source` installs now download LibreOffice and pnpm, check out submodules and install clio-kit while clio-agent itself installs, and unpack LibreOffice in parallel. Before, each step waited for the previous one (#2080).

## Fixed

- The Linux lite AppImage finds and starts its agent on a clean home directory instead of falling back to the connect form after several minutes (iowarp/gact-tui#1123).
- The first-run ask to enable notifications appears in the bell instead of covering the start of the answer (iowarp/gact-tui#1121).
- The Files list, @-reference search and the agent's directory listing no longer show the empty placeholder folders the Linux sandbox mounts while a command runs, or CLIO's own document preview folders (#2088).
- Shutting the server down stops a provider process still running under it, and a turn interrupted by shutdown says so instead of reporting that you cancelled it (#2088).
- `install.sh --desktop` now stops with the cause and the command to re-run when preparing the desktop runtime fails or the app executable is missing. Before, it printed a warning and reported success (#2077, #2081).
- On Linux, fetching LibreOffice's supporting packages retries when snapshot.ubuntu.com returns temporary server errors (#2084).
- Document tools running inside the sandbox get a writable LibreOffice profile, so conversions no longer fail there (#2084).
- The reasoning timer in a conversation stops while a tool call waits for your permission (#2084).
- Listing a conversation's artifacts no longer holds up other requests (#2084).
- `clio stop` stops a server that has exited but was not yet cleaned up, and `clio restart` keeps Web running (#2084).
- `SHA256SUMS.web.txt` names the Web zip by file name instead of the build machine's path, so `sha256sum -c` works on it (#2084).
