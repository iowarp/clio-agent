CLIO v0.9.5-beta.5 adds portable conversation reviews, clearer document previews and a more consistent workspace. It is a prerelease for users who opt into beta updates. It supersedes the incomplete beta.4 release and pins the verified, main-based GACT v0.11.3-beta.7, marketplace v0.6.11 and schemas 0.6.0b4 releases.

### Portable conversation reviews

Download a conversation as a self-contained HTML file with complete recorded tool inputs, results and loaded skills. Effects exports include that session and its children; Full exports also include the workspace snapshot, with file checksums and explicit omissions. (#1635)

### Documents and file previews

The standard agent can create and edit PDF, Word, PowerPoint and Excel files, with managed tools for rendering and review. Word and PowerPoint remain editable deliverables, with review PDFs linked to the correct document version. File previews share download, open, information and fullscreen controls, and document lineage starts from the editable source. (#1634, #1638, #1641; gact-tui #547)

### Conversation activity

Recorded reasoning, progress and tool results use one compact timeline with expandable details. Provider/model changes mark new transcript segments, and message footers show reported status, token usage, cost and tool counts when available. (#1641; gact-tui #547)

### Settings and models

New session defaults use the same searchable provider/model picker as the conversation. Runtime preferences explain where they apply, and reasoning-effort saves finish when the write is acknowledged. (#1641; gact-tui #547)

### Context and ongoing work

The toolbar toggle controls context and output showcases above ongoing work. Panels use available side space, narrow-window flyouts dismiss on outside click, and folder browsing loads directories in bounded pages. (#1639; gact-tui #546, #547)

### Source access and GitHub releases

Source sign-in is shared with the client, and recorded context can be recovered without inventing missing content. GitHub release questions check live publication metadata so drafts and prereleases are distinguished from published stable releases. (#1637, #1641)

### Larger displays and guides

Saved interface sizing improves readability on large displays, alongside more consistent Settings rows, dialogs and composer contrast. The website includes larger-screen typography and real report/slide generation walkthroughs. (#1640, #1642; gact-tui #548)

## Fixed

- Selecting a blueprint waits for background server preparation to finish, avoiding setup errors in idle sessions. (#1645)
- Windows bundle checks now probe all five clio-core endpoints outside the OS ephemeral range before testing the relocated runtime. (#1644)
- Codex and Claude Code model filters report usable CLIO tools for their actual transports. (#1641)
- Repeated activity previews are collapsed while complete stored evidence remains available. (#1641; gact-tui #547)

## Known limitations

The pinned clio-core 2.2.1 package omits the optional search indexer. ARC persistence works; indexed segment search reports that limitation.
