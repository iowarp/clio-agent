This is the fourth hotfix for the v0.9.6-beta.1 beta. It makes clean Linux installs work again while snapshot.ubuntu.com is down, and it makes every install smaller by leaving out LibreOffice files that document conversion never reads. Everything in [v0.9.6-beta.1.3](https://github.com/iowarp/clio-agent/releases/tag/v0.9.6-beta.1.3) is included.

### Linux installs work while snapshot.ubuntu.com is down

Four of LibreOffice's supporting packages are older versions that the Ubuntu archive no longer serves, and the only other sources were snapshot.ubuntu.com and a Launchpad redirector, both failing today. Every fresh Linux install, including the earlier betas' one-line install, stopped there. The installer now fetches those four packages from their permanent Launchpad file addresses and still checks each against its pinned checksum (#2104).

### Smaller, faster installs

The bundled runtime no longer carries LibreOffice's spelling and thesaurus data or its non-English configuration packs, which makes the download about 55 MiB smaller and LibreOffice's first start faster (#2103). When an install downloads LibreOffice itself, it skips writing those files instead of deleting them afterwards, which saves about 14 seconds on Windows (#2105).
