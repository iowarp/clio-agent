CLIO 0.9.6 brings a redesigned interface for Desktop and Web, a signed and notarized macOS app, much faster installs on Windows, macOS and Linux, scripts and live data streams for the agent, and a new Google Drive sign-in. It replaces 0.9.5.1 as the current release; desktops on 0.9.5.1 or a 0.9.6 beta offer the update.

## Install

Desktop (the app plus its own agent):

- macOS 15 or newer (Apple silicon) and Linux: `curl -fsSL https://clio.iowarp.ai/desktop.sh | bash`
- Windows: `irm https://clio.iowarp.ai/desktop.ps1 | iex`

Agent and Web only (open it with `clio web`, or run it headless with `clio start`):

- macOS and Linux: `curl -fsSL https://clio.iowarp.ai/install.sh | bash`
- Windows (PowerShell): `irm https://clio.iowarp.ai/install.ps1 | iex`

You can also download an installer from the assets below. The `-bundled` files carry the agent inside the app and work offline after download; the others download the agent on first launch.

- Windows: `CLIO.Desktop_0.9.6_x64_en-US-bundled.msi` or `CLIO.Desktop_0.9.6_x64-setup-bundled.exe`
- macOS: `CLIO.Desktop_0.9.6_aarch64-bundled.dmg`
- Linux: `CLIO.Desktop_0.9.6_amd64-bundled.deb`, `CLIO.Desktop-0.9.6-1.x86_64-bundled.rpm` or the `.AppImage` (arm64 builds are listed too)

The [installation guide](https://github.com/iowarp/clio-agent/blob/v0.9.6/docs/INSTALL.md) covers containers, source installs and uninstalling.

## Before you upgrade

Data saved by 0.9.5.1 or older does not open in this release. Conversations, memory and artifacts from that version stay on disk but do not show. The installer detects the old store and offers to move it aside; nothing is deleted, and your workspace files are not affected. `clio store-check` says which version wrote your data, and `clio reset-store` moves it aside when you upgrade without the installer.

Google Drive sign-in moved to a new Google client, so you may need to sign in to Drive again. Until Google finishes verifying the new client, only accounts the CLIO team has added can sign in. If yours is refused, ask your CLIO contact to add it.

The default port is now 17800 (it was 8100). Update bookmarks, scripts and firewall rules that use `localhost:8100`, or keep the old port with `gact.port` in your CLIO config or `--port`. (#1966)

CLIO Desktop for macOS now requires macOS 15 or newer.

### New interface

Desktop and Web share a redesigned interface. Notebook is the default look in light and dark; files, sources, artifacts, activity, terminal and browser open as tabs beside the conversation; and a conversation rail shows context use, goals, questions, todos and running work. Tool calls, thoughts and memory updates read the same way in the transcript, and everything between two updates folds into one row. Office files open in a rendered preview with Export to PDF beside Download. The [interface release notes](https://github.com/iowarp/gact-tui/releases/tag/v0.12.0) list every change. (#2030, #2036, iowarp/gact-tui#1122, iowarp/gact-tui#1131)

### Faster installs on every platform

The one-line installs now download the release's prebuilt agent runtime and unpack it while it downloads, instead of installing about 300 packages from PyPI. On Linux the prepared LibreOffice tree comes with the release too, so installs no longer depend on Ubuntu's package hosts being up. Store upgrades, uv and LibreOffice are set up alongside the download instead of one after another. (#2063, #2109, #2110, #2119, #2121, #2125, #2127)

### A signed and notarized macOS app

The macOS app, its helper and every program in its bundled runtime are signed with CLIO's Developer ID and notarized by Apple, so a downloaded app opens without an "Open Anyway" step and can be shared directly. CLIO no longer needs Xcode's Command Line Tools and never opens the dialog that offers to install them. (#1978, #1966, #2106)

### Agents and plugins

The default agents and plugins move to [CLIO Marketplace 0.8.0-beta.1](https://github.com/iowarp/clio-agent-marketplace/releases/tag/v0.8.0-beta.1). It adds an NDP agent for National Data Platform work, LaTeX paper writing with venue templates, an in-app browser the agent drives from code and pairing on a live marimo notebook.

### Scripts and live data streams

The agent can write a Python script that calls its own tools and reads only what the script prints. Running a script is one approval. A script can run in the background, report its progress and keep running after the turn ends. Streams keep a live table that views and dashboards read while it grows. (#1924)

### Long conversations stay on track

The agent keeps a session plan you can see and edit in the Work panel. It loads rarely used tools only when it needs them, and after a conversation is compacted it can recall the earlier steps the summary replaced. (#1924)

### More in this release

The file viewer opens HDF5 files, reading only the slices it shows (#1834, #1910). A conversation can move to another workspace with its delegated work and tool output (#2014). Installing Claude Code or another provider from the provider picker works right away without restarting CLIO (#1980, #1984, #2023). Workflow steps start as soon as the steps they depend on have finished (#1926).

## Fixed

- The Windows desktop no longer hangs and crashes shortly after it starts. (#2098, iowarp/gact-tui#1129)
- On the Windows desktop, installing Claude Code, Copilot or ALCF support no longer breaks the app. (#2123)
- A lite desktop app installs the agent version that matches it. (iowarp/gact-tui#1126)
- CLIO's runtime log can no longer fill the disk. (#1983)
- CLIO's store accepts connections only from this computer. (#1966, #2037, #2040)
- The app waits until CLIO is ready instead of showing errors while it starts. (#1966)
- Web search and the other bundled tools work from the app without first running the command line installer. (#1976, #2007)
- Quitting CLIO no longer hangs while its store stops, and `clio stop` also stops the services CLIO started, such as web search. (#2028, #2114)
- `clio uninstall` also removes the uv, uvx and clio-kit that the installer added. (#2112)
- A fresh install no longer reports its data store as degraded. (#2128)

## Changed

- The sandbox that confines the agent's commands is active on macOS and Linux app installs, where it was silently off. (#1966)
- Permission questions wait until they are answered instead of expiring after ten minutes.
- Installs leave out LibreOffice's spelling data and non-English configuration packs, which document conversion never reads. (#2103, #2105)

## Breaking

Data saved by 0.9.5.1 or older must be moved aside, as described above. The default port moved from 8100 to 17800. (#1966)

## Known issues

- Installs do not yet meet our one minute goal everywhere. In our measurements on a fast connection: the Windows desktop installs in about 55 seconds; the one-line install takes about 45 seconds on Linux, about 60 seconds on macOS and about 80 seconds on Windows. Slower links take longer, mostly in the download.
- On a fresh install with no conversations yet, attaching a newly connected Drive folder stops at "Choose a conversation to track this work". Start a conversation first. ([iowarp/gact-tui#873](https://github.com/iowarp/gact-tui/issues/873))
- Right after a release, the one-line install can report "no version of clio-agent" for up to 10 minutes while PyPI's index refreshes. Try again a few minutes later.

See the [CHANGELOG](https://github.com/iowarp/clio-agent/blob/v0.9.6/CHANGELOG.md). For a backend-only install: `uv tool install --python 3.14 --with dspy==3.4.0 --with fastmcp==4.1.2 --with fastmcp-tasks==4.1.2 --with mcp==2.2.0 clio-agent==0.9.6`
