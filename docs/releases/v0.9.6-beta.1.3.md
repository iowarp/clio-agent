This is the third hotfix for the v0.9.6-beta.1 beta. It makes the Windows desktop app usable, has the lite desktop app install the beta agent, and keeps Linux installs working while snapshot.ubuntu.com is down. Everything in [v0.9.6-beta.1.2](https://github.com/iowarp/clio-agent/releases/tag/v0.9.6-beta.1.2) is included, so all three systems have bundled desktop installers again.

### The Windows desktop app works again

In the earlier betas the Windows desktop app gave its agent a long-path form of its data folder (starting with `\\?\`). The agent then stopped answering, requests failed, and it crashed about 40 seconds after starting. The app now passes plain paths, and the agent accepts either form (#2098, iowarp/gact-tui#1129).

### Faster first launch

The desktop no longer re-checks every managed package on its first launch just because it was started from a different place than the installer, such as the Start menu instead of a terminal (#2099, iowarp/gact-tui#1130). On Windows the server is also ready several seconds sooner: the startup check for leftover processes reads the process list once instead of once per process (#2100).

## Fixed

- The lite desktop app's first install and Repair install the matching beta agent instead of the latest stable release (iowarp/gact-tui#1126).
- On Linux, fetching LibreOffice's supporting packages falls back to the Ubuntu archive when snapshot.ubuntu.com is unavailable. Since about 10:53 UTC today that service has been failing, which broke every Linux install path (#2097).
- The Linux bundled desktop deb and rpm build again (#2090).
