This is a hotfix for the v0.9.6-beta.1 beta. It makes installs that download LibreOffice reliable and shortens the Linux one-line install; everything else is the same as [v0.9.6-beta.1](https://github.com/iowarp/clio-agent/releases/tag/v0.9.6-beta.1).

### Installs no longer stall on a slow LibreOffice mirror

The document tools need LibreOffice, which CLIO downloads during install. The download site sends each request to a random mirror, and about one request in ten went to a mirror slow enough to push the install past its time limit. CLIO now tries several mirrors at once, keeps the fastest, and switches to another mirror if the transfer slows down, resuming where it stopped. Every file is still checked against its pinned checksum (#2077).

### Faster Linux one-line install

On Linux, the one-line and `--source` installs now download LibreOffice and pnpm, check out submodules and install clio-kit while clio-agent itself installs, and unpack LibreOffice in parallel. Before, each step waited for the previous one (#2080).

## Fixed

- `install.sh --desktop` now stops with the cause and the command to re-run when preparing the desktop runtime fails or the app executable is missing. Before, it printed a warning and reported success, leaving the work to the first launch (#2077, #2081).
