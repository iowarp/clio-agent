CLIO v0.9.5-beta.5.1 fixes a Windows bundled-installer failure in beta.5. Install this hotfix instead of beta.5. It retains the same released GACT v0.11.3-beta.7, marketplace v0.6.11 and schemas 0.6.0b4 dependencies.

## Windows installation

The managed Office renderer now extracts correctly under paths containing spaces, including CLIO Desktop's default storage location. This prevents the unexpected Windows Installer help popup and the subsequent bundled-runtime installation failure (error1639).

## Update channels

The hotfix has a distinct Python package version, `0.9.5b5.post1`, and Desktop updater version, `0.9.5-5+1`. Beta container tags stay separate from the stable `latest` channel. Existing beta.5 tags and packages have not been replaced.

## Platform availability

macOS Desktop qualification is deferred for this beta under explicit release approval. Missing macOS Desktop installers and updater entries will be added after their builds and packaged startup checks pass. Windows/Linux Desktop, web, CLI/TUI and Python packages remain available.

## Known limitations

The pinned clio-core 2.2.1 package omits the optional search indexer. ARC persistence works; indexed segment search reports that limitation.
