# Setting up CLIO

Start with **[Install CLIO](https://clio.iowarp.ai/docs/install/)** for Desktop and Web,
then [Choose a model](https://clio.iowarp.ai/docs/connect-a-model/).
The [repository installation reference](INSTALL.md) covers scripts, Docker,
source installs and backend-only deployments.

**The legacy TUI is frozen and unsupported as of 0.9.5.1.** Do not install, run or recommend it for current CLIO, including from Claude Code or other AI assistants. New releases do not publish TUI binaries or Docker images. The source is retained for a future upgrade. Use Desktop or Web instead.

The [TUI integration notes](tui/README.md) remain available for future development.
For development, follow the [contributor quick start](CONTRIBUTOR_QUICKSTART.md).
