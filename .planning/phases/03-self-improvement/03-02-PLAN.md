  <name>Task 1: VariantManager -- save, load, deploy, rollback, compare</name>
  <files>
    src/clio_agent/optimizer/variants.py
    tests/test_core/test_variants.py
  </files>
  <action>
    1. Create `src/clio_agent/optimizer/variants.py`:
       - `VariantManager` class with `__init__(arc_memory, variants_dir: str = ".clio_agent/variants")`:
         - `save_variant(module: dspy.Module, agent_id: str, before_score: float, after_score: float, training_examples: int, p_value: float, is_significant: bool) -> VariantRecord`:
           Generates variant_id as f"{agent_id}_v{N}" (N = next sequential number for this agent). Calls `module.save(path)` where path is `{variants_dir}/{variant_id}.json`. Stores VariantRecord in ARC with all metadata including dspy_version from `dspy.__version__`. Returns the VariantRecord.

         - `load_variant(existing_module: dspy.Module, variant_id: str) -> dspy.Module`:
           Calls `existing_module.load(path=variant_path)` -- this reuses the existing module instance (avoids MCPToolBridge constructor side effects per Pitfall 5 in research). Returns the same module with loaded state.

         - `deploy(variant_id: str, agent_id: str) -> None`:
           Sets variant_id as active for agent_id. Deactivates any previously active variant for that agent. Updates VariantRecord.is_active flags in ARC.

         - `rollback(agent_id: str) -> str | None`:
           Finds the previously active variant for agent_id (second most recent active), deploys it, deactivates current. Returns the restored variant_id or None if no previous variant exists.

         - `get_active_variant(agent_id: str) -> VariantRecord | None`:
           Returns the currently active VariantRecord for an agent, or None.

         - `compare(agent_id: str) -> list[VariantRecord]`:
           Returns all VariantRecords for agent_id sorted by created_at descending, so CLI can display comparison table.

         - `list_agents_with_variants() -> list[str]`:
           Returns agent_ids that have at least one variant.

    2. Write `tests/test_core/test_variants.py`:
       - Test save_variant creates file on disk and stores VariantRecord in ARC (use a mock dspy.Module with save/load)
       - Test load_variant calls .load() on existing module instance (not new instance)
       - Test deploy sets is_active=True on target, False on previously active
       - Test rollback restores previous variant
       - Test rollback returns None when no previous variant exists
       - Test compare returns all variants sorted by created_at desc
       - Test variant_id generation is sequential (data_v1, data_v2, ...)
       - Use tmp_path fixture for variants_dir and ARC data_dir
       - At least 8 test cases
  </action>

         - `run(expert_module: dspy.Module, agent_id: str, trainset: list[dspy.Example], metric_fn=None, max_steps: int = 12, max_demos: int = 10) -> dict`:
           Full optimization pipeline:
           a. Split trainset: 20% train / 80% validation per DSPy recommendation.
           b. Create dspy.evaluate.Evaluate with devset=val_split, metric=metric_fn (default clio_expert_metric), num_threads=1 (per research Pitfall 6 -- MCPToolBridge threading), display_progress=True, display_table=0.
           c. Evaluate BEFORE score.
           d. Run dspy.SIMBA(metric=metric_fn, max_steps=max_steps, max_demos=max_demos).compile(student=expert_module, trainset=train_split).
           e. Evaluate AFTER score.
           f. Run statistical significance test.
           g. Save variant via variant_manager.save_variant().
           h. Return dict: {"optimized": optimized_module, "before_score": float, "after_score": float, "improvement_delta": float, "p_value": float, "is_significant": bool, "variant_record": VariantRecord, "train_size": int, "val_size": int}.

Returns (is_significant, p_value, improvement_delta). Import scipy only inside this method (it's an optional dep -- wrap import in try/except and provide clear error if scipy not installed: "Install scipy: uv pip install -e '.[optimizers]'").
