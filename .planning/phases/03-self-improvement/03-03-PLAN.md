       d. Get expert module from agent: agent.data_expert / agent.analysis_expert / agent.visualization_expert.

       h. Call runner.run(expert_module, expert_id, trainset). Catch exceptions and show error.
       i. Print results table: Before Score, After Score, Delta, p-value, Significant (Yes/No).
       j. If significant, prompt: "Deploy this variant? [y/N]". On 'y', call variant_manager.deploy(variant_record.variant_id, expert_id), print "Variant {id} deployed".
       k. If not significant, print yellow warning: "Improvement not statistically significant. Variant saved but not deployed."

    2. Add `/metrics` command to handle_command():
       a. Import MetricsAggregator from optimizer.instrumentation.
       b. Create Rich Table with columns: Expert, Success Rate, Avg Latency (ms), Total Invocations, Cache Hit Rate.
       c. For each expert in ["data", "analysis", "visualization"]:
          Call aggregator.compute_expert_metrics(expert_id).
          Add row with formatted values (percentages, 1 decimal ms).
       d. Print table. If no invocations for any expert, show "No invocation data yet. Run some queries first."

    3. Add `/compare [expert_id]` command to handle_command():
       a. If no expert_id provided, show usage: "/compare <data|analysis|visualization>".
       b. Create VariantManager(agent.arc).
       c. Call variant_manager.compare(expert_id).
       d. Display Rich Table: Variant ID, Before, After, Delta, p-value, Significant, Active, Created.
       e. If no variants, print "No variants found for {expert_id}."

    4. Add `/rollback [expert_id]` command to handle_command():
       a. If no expert_id provided, show usage: "/rollback <data|analysis|visualization>".
       b. Create VariantManager(agent.arc).
       c. Call variant_manager.rollback(expert_id).
       d. If restored, print green: "Rolled back to variant {id}". Load variant state into the running expert instance via variant_manager.load_variant().
       e. If None returned, print yellow: "No previous variant to rollback to."

    5. Update print_help() to include /metrics, /compare, /rollback commands.

    6. Modify `src/clio_agent/agent.py` __init__:
       After creating experts (lines ~118-124), check for active variants:
       ```
       from clio_agent.optimizer.variants import VariantManager
       vm = VariantManager(self.arc)
       for agent_id, expert_attr in [("data", "data_expert"), ("analysis", "analysis_expert"), ("visualization", "visualization_expert")]:
           active = vm.get_active_variant(agent_id)
           if active and Path(active.file_path).exists():
               try:
                   vm.load_variant(getattr(self, expert_attr), active.variant_id)
                   if self.verbose:
                       print(f"[ClioAgent] Loaded variant {active.variant_id} for {agent_id}")
               except Exception as e:
                   if self.verbose:
                       print(f"[ClioAgent] Warning: Could not load variant for {agent_id}: {e}")
       ```
       Wrap in try/except so variant loading failure never breaks agent startup.
