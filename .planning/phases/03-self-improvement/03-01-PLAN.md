         - `generate(agent_id: str, min_examples: int = 30) -> list[dspy.Example]`: calls arc_memory.get_invocations_by_agent(agent_id, status="success"), converts each to dspy.Example matching the expert signature fields (question, file_context as inputs; analysis, recommendations as labels). Raises ValueError if < min_examples found. Returns examples sorted by started_at descending (most recent first).
         - `get_available_counts() -> dict[str, int]`: returns {agent_id: count} for all agents with invocations, so CLI can show readiness.

       - `clio_expert_metric(example, pred, trace=None) -> float | bool`:
         Multi-signal metric per research (03-RESEARCH.md Pattern "Complete Metric Function"):
         - Signal 1 (0.4): analysis field non-empty and >20 chars
         - Signal 2 (0.3): recommendations field non-empty and >20 chars
         - Signal 3 (0.3): no error keywords in output
         - When trace is not None (optimization mode): return score >= 0.7 (boolean gate)
         - When trace is None (evaluation mode): return float score
         Handle VisualizationExpert outputs too: visualization_description maps to analysis weight, file_path existence maps to recommendations weight.
