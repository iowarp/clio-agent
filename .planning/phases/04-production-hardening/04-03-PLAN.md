Create Dockerfile (PROD-05) -- multi-stage build for small image:

```dockerfile
# Stage 1: Build
FROM python:3.12-slim AS builder
WORKDIR /app
COPY pyproject.toml uv.lock ./
RUN pip install uv && uv sync --frozen --extra api --extra optimizers --no-dev

# Stage 2: Runtime
FROM python:3.12-slim
WORKDIR /app
COPY --from=builder /app/.venv /app/.venv
COPY src/ ./src/
ENV PATH="/app/.venv/bin:$PATH"
ENV CLIO_ENVIRONMENT=production
EXPOSE 8000
HEALTHCHECK --interval=30s --timeout=5s --retries=3 \
  CMD python -c "import urllib.request; urllib.request.urlopen('http://localhost:8000/health')" || exit 1
ENTRYPOINT ["uvicorn", "clio_agent.ui.api:app", "--host", "0.0.0.0", "--port", "8000"]
```

Key details:
- Multi-stage: builder installs deps, runtime copies only .venv and src
- Uses UV for fast dependency resolution
- HEALTHCHECK hits /health endpoint
- CLIO_ENVIRONMENT defaults to production
- All CLIO_* env vars passed through at runtime (not baked in)
- No LM Studio URL baked in -- uses env vars

Create docker-compose.yml (PROD-07):

```yaml
services:
  clio-agent:
    build: .
    ports:
      - "8000:8000"
    environment:
      - CLIO_LM_PROVIDER=${CLIO_LM_PROVIDER:-lm_studio}
      - CLIO_LM_API_BASE=${CLIO_LM_API_BASE:-http://host.docker.internal:1234/v1}
      - CLIO_LM_MODEL=${CLIO_LM_MODEL:-}
      - CLIO_LM_API_KEY=${CLIO_LM_API_KEY:-lm-studio}
      - CLIO_ENVIRONMENT=production
    volumes:
      - clio-data:/app/.clio_agent
    healthcheck:
      test: ["CMD", "python", "-c", "import urllib.request; urllib.request.urlopen('http://localhost:8000/health')"]
      interval: 30s
      timeout: 5s
      retries: 3
    restart: unless-stopped

volumes:
  clio-data:
```

Key details:
- Uses host.docker.internal for LM Studio on host machine (standard Docker pattern)
- Environment variables with defaults via ${VAR:-default} syntax
- Persistent volume for .clio_agent data (ARC memory, LSM, variants)
- Healthcheck mirrors Dockerfile HEALTHCHECK
- No LM Studio container in compose (it runs on host, not in Docker)
