<task type="auto">
  <name>Task 1: FastAPI REST API with SSE streaming</name>
  <files>src/clio_agent/ui/api.py, tests/test_core/test_api.py</files>
  <action>
Replace the stub api.py with a full FastAPI application. The [api] optional dependencies (fastapi, uvicorn, sse-starlette) are already in pyproject.toml.

Create the FastAPI app with these endpoints:

**POST /query** (PROD-01, PROD-02):
- Request body: `{"question": str, "session_id": str = "default", "stream": bool = False}`
- If stream=False: return JSON `{"answer": str, "selected_expert": str, "session_id": str, "duration_ms": float, "error_info": dict | None}`
- If stream=True: return SSE (text/event-stream) with events:
  - `event: routing` data: `{"selected_expert": "data"}`
  - `event: chunk` data: `{"text": "partial answer"}` (since DSPy is not natively streaming, simulate by splitting the final answer into word chunks with small delays -- this gives the SSE infrastructure for when real streaming is added)
  - `event: done` data: `{"answer": "full answer", "selected_expert": "data", "duration_ms": 123.4}`
  - `event: error` data: `{"error": "...", "message": "..."}` on failure
- Use `from sse_starlette.sse import EventSourceResponse` for SSE
- Wrap agent.forward() call, catch exceptions, return structured errors via format_error_response from errors.py

**GET /health** (PROD-01):
- Return `{"status": "ok", "version": "0.2.0", "provider": config.provider, "environment": config.environment}`
- If agent not initialized (LM provider down), return `{"status": "degraded", "error": "..."}`

**GET /experts** (PROD-01):
- Return list of registered experts with capabilities from agent.registry
- Format: `{"experts": [{"id": "data", "description": "...", "keywords": [...], "tools": [...]}]}`

**GET /metrics** (PROD-01):
- Return per-expert metrics from MetricsAggregator
- Format: `{"metrics": {"data": {"success_rate": 0.85, ...}, "analysis": {...}, "visualization": {...}}}`

**Application lifecycle:**
- Use FastAPI lifespan context manager
- On startup: load_config_from_env(), setup_dspy(), create ClioAgent instance, store in app.state
- On shutdown: agent.shutdown()
- Global exception handler: catch all unhandled exceptions, return format_error_response (never raw tracebacks)

**main() function:**
- Parse --host (default 0.0.0.0), --port (default 8000), --reload args
- Run with `uvicorn.run(app, host=host, port=port)`

Write tests in test_api.py using `from fastapi.testclient import TestClient`:
- Mock ClioAgent to avoid LM Studio dependency (patch at module level before importing app)
- Test GET /health returns 200 with status/version/provider
- Test POST /query with stream=False returns JSON with answer and selected_expert
- Test POST /query with stream=True returns text/event-stream content type
- Test POST /query with invalid body returns 422
- Test GET /experts returns expert list
- Test GET /metrics returns metrics dict
- Test error handling: mock agent to raise, verify structured error response (not traceback)
- At least 10 tests covering happy path and error cases

<task type="auto">
  <name>Task 2: GitHub Actions CI and pre-commit hooks</name>
  <files>.github/workflows/ci.yml, .pre-commit-config.yaml</files>
  <action>
Create .github/workflows/ci.yml for GitHub Actions CI (PROD-03):

```yaml
name: CI

on:
  push:
    branches: [main, "v*"]
  pull_request:
    branches: [main]

jobs:
  lint:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: astral-sh/setup-uv@v5
        with:
          version: "latest"
      - run: uv sync --extra dev --extra api --extra optimizers
      - run: uv run ruff check src/ tests/
      - run: uv run ruff format --check src/ tests/

  typecheck:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: astral-sh/setup-uv@v5
        with:
          version: "latest"
      - run: uv sync --extra dev --extra api --extra optimizers
      - run: uv run mypy src/clio_agent/ --ignore-missing-imports

  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: astral-sh/setup-uv@v5
        with:
          version: "latest"
      - run: uv sync --extra dev --extra api --extra optimizers
      - run: uv run pytest tests/ --cov=clio_agent --cov-report=term-missing --cov-fail-under=80 -x
```

Key details:
- Use `astral-sh/setup-uv@v5` for fast UV installation
- Install all extras needed: dev, api, optimizers
- Three parallel jobs: lint, typecheck, test
- Coverage gate at 80% via `--cov-fail-under=80`
- Trigger on push to main and v* branches, and on PRs to main

Create .pre-commit-config.yaml (PROD-04):

```yaml
repos:
  - repo: https://github.com/astral-sh/ruff-pre-commit
    rev: v0.9.6
    hooks:
      - id: ruff
        args: [--fix]
      - id: ruff-format
```

This runs ruff check with auto-fix and ruff format on every commit. The rev should be a recent stable ruff version.
