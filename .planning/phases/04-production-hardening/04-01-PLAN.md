Create src/clio_agent/errors.py with structured error types:

```python
class ClioError(Exception):
    """Base error for all CLIO Agent errors."""
    def __init__(self, message: str, error_type: str, details: dict | None = None):
        self.message = message
        self.error_type = error_type
        self.details = details or {}
        super().__init__(message)

    def to_dict(self) -> dict:
        return {"error": self.error_type, "message": self.message, "details": self.details}
```

Subclasses:
- `ProviderError(ClioError)` -- LM provider unavailable/timeout (error_type="provider_error")
- `RoutingError(ClioError)` -- Router failed to classify (error_type="routing_error")
- `ExpertError(ClioError)` -- Expert execution failed (error_type="expert_error")
- `ToolError(ClioError)` -- MCP tool call failed (error_type="tool_error")
- `ConfigError(ClioError)` -- Configuration invalid (error_type="config_error")

Add a helper function `format_error_response(error: Exception) -> dict` that:
- If ClioError: return error.to_dict()
- If other Exception: return {"error": "internal_error", "message": "An internal error occurred", "details": {}} -- never expose raw traceback

Add a function `with_degradation(primary_fn, fallback_fn, error_cls=ClioError)` that:
- Tries primary_fn()
- On exception, logs warning, tries fallback_fn()
- If fallback also fails, raises error_cls with both messages

Update agent.py forward() to wrap dispatch errors:
- Router failure: catch Exception, wrap as RoutingError, fall back to "chat" (already done, just use RoutingError class)
- Expert failure: catch Exception, wrap as ExpertError, return structured error message instead of raw traceback
- The error message returned to user should be: `{"error": "expert_error", "message": "...", "expert": selected}` -- but since forward() returns dspy.Prediction with answer string, format the answer as a user-friendly message (not JSON) for CLI, and store the structured error in the prediction metadata.

Add `error_info` field to the Prediction return: `error_info=error.to_dict() if error else None`

Update agent.py to use `create_lm` and `create_router_lm` from config.py instead of the old `configure_dspy_lm_studio` / `configure_dspy_router_lm_studio` functions. Update the __init__ to call `load_config_from_env()` and use provider-agnostic LM creation. Keep fetch_lm_studio_models/select_models_for_agents only when provider is lm_studio.
