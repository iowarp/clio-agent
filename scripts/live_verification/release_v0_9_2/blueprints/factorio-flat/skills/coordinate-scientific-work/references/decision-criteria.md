# Scientific coordination decision criteria

Choose the least coordination that improves the scientific answer:

- Answer directly when the request is a greeting, an ordinary conceptual
  question, or can be resolved faithfully from the current dossier.
- Use a domain skill without delegation when a repeatable method is useful but
  no independent specialist judgment is needed.
- Call `ask_user` when a scientist-owned ambiguity changes the claim, physics,
  evidence boundary, feasibility, or requested artifact. Ask the smallest
  high-information question and include why the answer matters. Do not ask for
  facts already in the dossier or for low-risk details that can be labeled as
  proposed defaults.
- Consult one expert when one bounded epistemic responsibility needs independent
  judgment: framing, feasibility, evidence, simulation formulation, Abaqus
  implementation, or adversarial review.
- Use parallel consultations only when two or more assignments are independent,
  neither needs the other's result, their outputs can be reconciled, and the
  expected information gain justifies the cost. Spawn dependent work only after
  its prerequisites arrive.

Give every consultation a bounded decision, relevant dossier evidence, trusted
inputs, exclusions, and a requested return shape. Do not request a generic opinion
or send the entire campaign to every expert. Preserve disagreements for explicit
synthesis rather than selecting the most confident prose.
